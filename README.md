# AI Debate Lab

AI Debate Lab — это мультиагентная система на основе больших языковых моделей, в которой специализированные агенты совместно анализируют задачи, предлагают решения, выдвигают альтернативы и формулируют окончательный вывод. В рамках проекта также изучается, как количество агентов, их роли и количество раундов взаимодействия влияют на качество получаемых решений.

## Как это работает

В обсуждении участвуют пять агентов:

- **Исследователь** — предлагает решение.
- **Критик** — выявляет слабые места и риски.
- **Оппонент** — рассматривает альтернативы.
- **Модератор** — сопоставляет мнения и фиксирует разногласия.
- **Судья** — анализирует обсуждение и подводит итоги.

Первые четыре агента работают последовательно. Все агенты используют одну языковую модель, но разные системные инструкции.

Ответы формируются в JSON и проверяются с помощью Pydantic.

## Технологии

Python, FastAPI, Pydantic, OpenAI SDK, Ollama, DeepSeek, HTML, CSS, JavaScript.

## Запуск проекта

Для работы приложения необходимы Python и [Ollama](https://ollama.com/).

Загрузите модель:

```bash
ollama pull qwen3:8b
```

Откройте терминал VS Code в папке проекта и активируйте виртуальное окружение:

```bash
source .venv/bin/activate
```

Установите зависимости (если ещё не установлены):

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
uvicorn app.main:app --reload
```

Веб-интерфейс: http://127.0.0.1:8000

Документация API: http://127.0.0.1:8000/docs

## Настройка языковой модели

По умолчанию используется локальная модель Ollama `qwen3:8b`. Настройки провайдера находятся в файле `.env`:
LLM_PROVIDER=ollama

**Если вы хотите использовать DeepSeek:**

1. Получите API-ключ на [DeepSeek Platform](https://platform.deepseek.com/).
2. Откройте файл `.env`.
3. Замените настройки на следующие:

LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=ваш_api_ключ
LLM_MODEL=deepseek-flash

4. Сохраните изменения и перезапустите приложение.

Чтобы вернуться к Ollama, достаточно снова указать `LLM_PROVIDER=ollama`.

## Смена модели

Для Ollama сначала загрузите нужную модель через терминал:

```bash
ollama pull название_модели
```

Затем измените название модели в `app/llm.py`.

Для DeepSeek измените значение `LLM_MODEL` в `.env` на название доступной модели.

После изменения настроек перезапустите приложение.

## Тестирование

```bash
python -m pytest -q
```

## Структура проекта

- `app/main.py` — FastAPI и API endpoints.
- `app/llm.py` — подключение к языковой модели.
- `app/config.py` — настройки приложения.
- `app/roles.py` — роли и инструкции агентов.
- `app/schemas.py` — схемы данных.
- `app/orchestrator.py` — логика обсуждения.
- `index.html`, `style.css` — веб-интерфейс.
- `tests/` — автоматические тесты.
